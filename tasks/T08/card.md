## Problem and research value

A post-training researcher inherits a tool-using model that was competent before several API and business-rule revisions. New feedback contains correct demonstrations for the latest contracts, while the fixed replay buffer still contains demonstrations from earlier releases. Some earlier targets are obsolete; others remain obligations. Later workflows reuse skills that temporarily disappeared from recent traffic. The researcher must change how parameters and optimizer state evolve so that the model learns the new obligations without destroying valid old and returning behavior.

This is an actual continual-learning question: when does protecting an old gradient preserve a useful capability, and when does it prevent necessary adaptation? Removing a demonstrably obsolete example is ordinary hygiene. The proposed research residue is whether protecting the right directions in the wrong optimizer metric, or retaining moments attached to a now-unneeded direction, damages shared prerequisites after subsequent updates. The task earns its place only if that residue is measurable after ordinary hygiene and the strongest known stack. It does not reward diagnosing drift in prose, collecting a better curriculum, or listing continual-learning methods.

The inherited project must contain real executions of its starter: release diffs, a chronological feedback ledger, fixed replay receipts, earlier learning curves, a baseline checkpoint and its optimizer state. Synthetic contract histories must be described as authored simulation histories. No fictitious production incident or fabricated run log is allowed. A real lab analogue is maintaining a compact tool policy during repeated interface and policy migrations when replay, storage and training compute are limited. The mechanism's transfer to larger subjects needs a scale check; no frontier-scale effect size is claimed here.

T08 resembles GDM's accepted `pretraining_latest` in that the artifact controls actual parameter learning and the verifier reconstructs training. Its endpoints resemble `agentic_search_inference_efficiency` in requiring completed tool workflows rather than proxy loss. It borrows `inference_optimization`'s insistence that checked work and metered work are the same execution. Its distinguishing scientific intervention is the continual update rule on a fixed stream. It reserves no accelerators for an essay or a grader audit. There is no souping, checkpoint averaging, model merging or expert-weight combination.

### Typed update program and all persistent bytes

The **ESTIMATED DSL** supports scalar expressions over public release descriptors, step counters, authorized minibatch losses and authenticated replay statistics; vector expressions over trainer-produced gradients, parameter-relative regularizers and declared state; and fixed-shape linear algebra. Legal primitives include nonnegative target weighting, supervised loss, replay loss, diagonal importance accumulation, momentum/second-moment updates, gradient dot products, masked low-rank QR/SVD projection, layer scaling, norm clipping, reset and transport of declared state. Scalar division uses an explicit positive floor; nonfinite results are typed failures. Floating-point scalar constants cannot be broadcast as arbitrary tensor directions. Dense literals, raw byte construction, arbitrary indexing into private inputs, filesystem/network access, imports, callbacks and dynamic module creation have no opcode.

The trusted interpreter constructs gradients from actual scheduled examples and loss operators. Every writable vector is initialized by the trainer to an approved zero/initial value and can subsequently depend only on those gradients, the current trainable parameters relative to their initial/reference state, and earlier declared vectors. Model writes are restricted to the manifest's trainable tensors through the declared update step. The program cannot return a tensor to replace a parameter, relabel a demonstration, change a replay receipt or install a forward hook. A scalar schedule can encode a lawful algorithm; it cannot acquire a side channel for arbitrary checkpoint bytes. This is a dataflow restriction to implement and test, not a claim that a text scanner proves provenance.

For low-rank projection, full vectors used as bases occupy declared vector slots. QR sign convention, singular-value ordering and tie handling are fixed in the interpreter. The **ESTIMATED initial limit is sixteen P-length fp32 auxiliary vectors in total**, shared among moments, importance estimates, prior parameter anchors and bases. That budget can fit a low-rank memory basis plus optimizer state, but does not grant each component its own unlimited allocation. Adam-like moments, reference parameters, Fisher/SI statistics, sparse masks, compressed summaries and conditional routing state all consume this same budget. Baseline authors must reduce ranks or other state to fit; they must not silently omit costs from the strongest recipe.

Define canonical counted bytes exactly as

`M = 4P + sum_k(4*numel(fp32_state_k)) + 8*numel(int64_state) + bytes(canonical_program_and_config) + bytes(serialized_rng_and_metadata)`.

The **ESTIMATED cap** is `M <= 4P + 64P + 1 MiB`; the last allowance covers program/config, bounded scalar registers, RNG and metadata, not another untyped blob. All runtime-persistent arrays use the canonical fp32/int64 representation; packed bits and compressed arrays are charged at their reconstructed canonical size. Views and aliases are charged per logical declared tensor, preventing compressed/aliased storage from buying effective capacity. The immutable shared backbone and fixed replay assets are reported separately and are identical for all methods. Temporary scratch is destroyed after each step and cannot survive through an undeclared device allocation, file, cache, child or service. Scheduled replay contents/IDs are fixed trainer assets; extra retained copies or hashes used as an auxiliary memory are forbidden by the state schema. Gradients can be reduced into declared state, and that state is counted.

At each release the trainer serializes every persistent tensor, RNG counter, scalar register and program configuration into canonical order, rebuilds a fresh worker from exactly that representation, and checks the next transition. Scoring loads only the effective model parameters through the fixed inference graph; optimizer memory has no inference API. The parent records effective parameter paths and loaded-module hashes. The grade rejects state over cap, undeclared tensors, multiple mutable model artifacts and mismatched provenance. Legal internal specialization within those parameters is not called cheating.

This DSL is deliberately a build risk. D11/C17 prototypes must show both a novel state-transport method and the full compatible known recipe fit it. If a recurrent learned optimizer is required, its parameters and recurrent state count against the same memory allowance and it needs a typed, bounded trusted opcode defined before freeze. No unrestricted callback is grandfathered in. If expressive and safe operation cannot coexist, narrow the claim to the admitted update class or cut T08.

## Deterministic grader and scientific outcome

The artifact is an update program. For each committed private seed, the parent reconstructs the starting state, replays every scheduled update, captures the effective model at every fixed endpoint, and runs deterministic greedy episodes in the current simulator. Each evaluation item has a trusted ID and fixed weight before the candidate starts. The candidate never submits answers, version labels, cohort membership, success flags or denominators.

An item succeeds exactly when its executed trace satisfies all mandatory safety constraints and reaches one accepted terminal state in the independent truth interpreter. Alternate semantically equivalent traces pass. Exact typed tool arguments and final integer/rational state determine truth; token overlap or a regex answer marker does not. A malformed tool call terminates that item with failure, as disclosed. Token limits and tool-call limits are identical across methods. Parser-format accuracy is reported separately to establish that apparent retention gains are semantic.

**ESTIMATED initial scientific strata:** each scored release × the three cohorts × two semantic workflow families × two disclosed difficulty bands. Give each stratum equal macro weight, and each offered item equal weight within it. The initial proposal has **ESTIMATED sixty-four independent scenario roots per stratum**. Varying paraphrases from one root does not increase independent n; all related endpoints are clustered by whole history. The freeze must publish the actual denominator manifest and supported content families. No empty stratum is allowed. Sample size is revised only on calibration/power evidence, with a version bump.

For seed s, endpoint t and semantic stratum j, let `y_stji` be executed item success in {0,1}; let `a_stji` be whether a bounded, schema-valid terminal response was completed, also in {0,1}. Missing, late and crashed items set both to zero. With fixed item count N_tj,

`q_stj = sum_i y_stji / N_tj`, and `v_stj = sum_i a_stji / N_tj`.

A slice has a numeric completion floor `v_stj >= 0.90` and quality floor `q_stj >= tau_tj`; 0.90 and the following non-regression allowance adopt B14's proposed defaults. Set `tau_tj = max(0, h_tj - 0.02)`, where h_tj is a frozen independently calibrated competent validity-filtered replay baseline's success in that slice. Thus every final tau is an actual numeric manifest entry. No unmeasured h or tau is fabricated in this packet. The old-valid slice also requires non-regression against the matched inherited-capability control within 0.02; use the larger of those two frozen quality floors. New and returning floors use the matched competent adaptation baseline, not an untrained model. Training seeds and subject sizes each receive their own certification rows; macro means cannot waive a failed seed or larger-subject slice.

To keep reward local and continuous, define the **ESTIMATED proposed penalty**

`d_stj = max(0, tau_tj - q_stj) + max(0, 0.90 - v_stj)`

`z_stj = q_stj - 0.5*d_stj`

`U_s = clip(sum_tj w_tj*z_stj, 0, 1)`, where `w_tj = 1 / number_of_committed_strata`.

`U = mean_s U_s` over the three private training seeds.

Raw cohort success, completion and each deficit are always reported alongside U. U is a penalized fraction of successfully completed current-contract workflows, on a bounded native probability scale. A full loss of an offered item changes its pre-curve contribution by at most twice its fixed macro weight: correctness slope is at most 1.5 and completion slope at most 0.5. The floor checks separately govern certification with resolved CIs. Crossing a floor does not void unrelated work or impose a global reward cliff. Obsolete examples have no old-valid credit, but the author fixes which targets are obsolete.

No continuous latency, report quality, diagnosis, detection, cleanup or experiment-count term is retained. The three capability cohorts each carry one third of the unpenalized macro outcome, an **ESTIMATED design weight**, and every retained penalty must prove liveness. B9 requires a term to move at least 1% of the reward range on at least 25% of rollouts or be dropped in a new version. If completion or either deficit is dead, remove it rather than retain decorative arithmetic. Do not add unconditional seeding/cache-cleaning credit. All positive outcome credit comes from executed subject behavior.
