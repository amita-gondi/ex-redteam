## The research problem and its value

A multimodal post-training researcher inherits a crop-and-seek agent that answers questions about crowded scenes and short event streams. It often looks at conspicuous objects repeatedly, fails to connect the same object across separated views, or answers after seeing only one part of a consequential relation. Improve its deployed answer accuracy while holding the amount of acquired visual evidence and its inference resources fixed. Both spatial selection and temporal revisits belong here because they compete for the same observation budget and can require the same persistent identity hypothesis.

For example, a question may refer to the container that a particular worker used before an exchange. An early view identifies the worker, a later view distinguishes an exchange from a nearby distractor event, and a close view reveals which container participated. This is a proposed content pattern, not a claim that such an item already exists. The next useful view must be inferable from earlier pixels. A hidden event graph cannot direct the agent to the right instant.

The R&D product is an improved acquisition/training method with reproducible learning and execution traces. It could help research agents inspect scientific imagery, debugging videos or visual interfaces with limited observation capacity. Transfer beyond the tested scene/event distribution is unproven. The researcher is rewarded for executed outcomes; a convincing ambiguity taxonomy, a prescribed crop order or a report receives no credit.

The accepted GDM examples supply useful comparisons. Like `pretraining_latest`, T10 must involve actual learned state, repeatable training and a meaningful constrained capability range. Like `inference_optimization`, the checked work must be the work executed within the resource contract. Like `agentic_search_inference_efficiency`, the whole evidence-gathering pipeline matters, and a local proxy must predict final performance. T10 does not become a GPU research task through simulated seek delays. If direct CPU scene parsing solves it and GPU training adds no meaningful outcome improvement, its accepted-shape claim fails.

## Observation contract: every useful view has a cost

All dimensions and budgets in this subsection are **ESTIMATED proposed T10 constants**, to be tested and frozen before anchors. This deliberately replaces the catalog's unspecified crop/frame/token envelope.

| Quantity | Proposed contract |
|---|---|
| Native media | Square RGB frames of 1,024 by 1,024 pixels. Static episodes contain one frame; temporal episodes contain 32 frames in disclosed chronological order. No audio. |
| Initial observation | Frame zero at full-frame extent, resized to 112 by 112 pixels. It consumes an observation slot and its complete pixel/token charge. There is no free global thumbnail. |
| Spatial request | A square crop with integer side in {128, 256, 512, 1,024}; top-left coordinates are multiples of 32 inside the frame. Output side is in {112, 224, 448}, and cannot exceed native crop side. |
| Temporal request | Frame index in the public valid range, plus the same spatial request. Seeking returns exactly that crop of one frame, never intermediate decoder frames. Both forward seeks and revisits are legal. |
| Observation slots | At most eight returned views including the initial observation. Repeating an identical view consumes a slot and the same charge. |
| Visual budget strata | Tight: 512 billable visual units; standard: 1,024. They are separately graded, equally weighted within each family. |
| Text and execution | At most 2,048 newly generated subject-model tokens per episode; maximum active subject context 8,192 tokens; 120 seconds episode execution on one reserved GPU, including controller/model calls and seeks. Padding and hidden reasoning tokens count if the runtime generates them. |
| Worker resources | One episode worker per GPU, at most eight concurrent workers; 4 GiB worker RAM and one CPU core per worker. All controller computation is charged. No outer-frontier calls in a deployed episode. |

For a returned image of output side r, define pixel bill `p(r)=r²/28²`; proposed sides make this an integer. Let `v(r)` be the **actual** count of image tokens emitted by the pinned trusted processor for that RGB tensor. Charge `q(r)=max(p(r),v(r))`. The processor's special tokens and resizing are recorded separately, and no undocumented automatic high-resolution tiling is allowed. Every returned crop consumes q even if the controller never invokes the VLM. Each additional visual encoding of a retained image also consumes q; using an already computed legal embedding or ordinary memory does not. Root-issued model receipts enforce the re-encoding count. Inspect actual processor output before freeze; this definition does not assume a particular Qwen patch-merging implementation.

The shared remaining visual budget is decremented atomically before a crop is returned or an extra encoding starts. No batch, cache, auxiliary model, training-time grade callback or multi-resolution request can return unpaid pixels. Crop resize is a pinned deterministic CPU operation from lossless canonical RGB; scorer truth is never embedded in image metadata. Root training and evaluation use the same processor and cost function. Classical image processing of acquired pixels is allowed and consumes execution time, while acquisition still consumes q.

Out-of-range coordinates/frames, exhausted budgets and malformed action requests return a fixed-size public status with no pixels, crop bounds, decoder exception, media path or hidden dimensions. Each consumes one action slot; exhaust the slots and the episode must answer from prior observations or lose the answer. Shape-valid errors depend only on the request and public counters. Response release uses a fixed public schedule within the episode cap, with padding determined independently of scene truth. Error timing, compressed byte length, EXIF, seek latency and decoder cache state are explicit leak-test surfaces. No worker receives private scene-graph access. Each world runs in a fresh worker so its paired sibling cannot be recognised through persistent memory.

Low-resolution whole-frame search is **legal** and is not forced to fail by a new rule. Run full-frame-only, no-pixel, uniformly tiled, hierarchical tiling and thumbnail-plus-targeted-crop controls. If legal cheap coverage matches the trained controller, the active-acquisition premise is cut. Spatial and temporal tasks must share the same documented seek/reset semantics in dev and grading.

## Causal observability, truth and fresh instances

The independent review correctly separates “some revealing path exists” from “a policy can choose it.” T10 now requires both an information-set audit and an executable nonanticipatory witness. A private path selected after looking at the answer is rejected as a certificate.

Let a legal history h contain the question, alternatives, paid pixel observations, previous actions and public counters. The policy is `a=π(h)` with fixed code/state initialisation, never `π(h,world_id,truth)`. Paired worlds with identical h must induce identical next-action distributions under identical policy randomness. This applies to the witness, trained reference and stronger control. Run them in separate reset workers and compare requests before and after the first visible distinguishing cue.

For finite author audit banks, partition worlds by identical legal observations and track each remaining-budget information set H. An author-only dynamic program computes the best attainable expected answer accuracy: stopping gives the largest posterior answer probability; an observation action gives the posterior-weighted value of its resulting information sets with its cost removed. Maximise over legal actions and stopping. Terminal and budget-exhausted states use only the posterior over answers. This is an **upper bound**, not an executable lower bound or a legal deployed controller. Log the explicit world distribution, transitions, action costs and proof coverage. Exhaustive audit on a reduced bank establishes that bank only; it cannot certify a larger renderer by analogy.

The immediate negative fixture hides the decisive object at different locations behind indistinguishable prefixes and gives no observable routing cue before the last affordable view. An answer-specific crop sequence may exist in every world, yet a common policy must guess where to look. The information-set audit must detect that limitation. A companion positive fixture introduces a visible routing cue whose meaning is supported by training evidence, then verifies that the same causal controller follows it correctly in both worlds. Changing a hidden tag while keeping every permitted observation identical must not change a legal controller's action or answer.

The executable witness receives exactly the deployed ABI, pixels, budgets and runtime. It is trained/constructed using only the legal training split, and its final reconstruction obeys the same training cap as any candidate. Proposed acceptance is **ESTIMATED at least 0.90 raw answer accuracy in every family×budget cell** on fresh author-validation content, together with paired-world nonanticipation tests. This is a feasibility goal, not achieved accuracy. If that controller is simply a known generic visual-search algorithm, include it in the recipe floor. A witness cannot be both evidence of attainability and conveniently excluded from the baseline challenge.

Primary content is privately authored scene/event compositions with explicit visibility conventions, persistent object identity, and answer-changing counterfactuals. Use at least two independently authored semantic/provenance families, as A11 requires; different seeds, colours or filenames are insufficient. For example, static relational layouts and temporally ordered exchanges must change which observations are useful, and compositions must require linking their evidence. Labels and alternative positions are balanced within the scored cells. Answer permutation, renderer style, object appearance, occlusion and serialization are crossed with truth so a prior-only or metadata policy is tested fairly.

Keep training, floor/endpoint calibration, author validation, protected dev, saturation-study blocks and final hidden banks disjoint at whole scene/event-logic and provenance-family boundaries. Use the bar's independently generated, domain-separated split secrets with at least 128-bit entropy, without pretending entropy creates semantic novelty. The final bank is unopened until freeze; any result used to change an interface, family, floor, difficulty level or recipe retires that bank for certification. Fresh private content is required for subsequent launches rather than recycling final answers.

Truth consists of exact relation/identity/event/composition answers rebuilt from the private scene/event specification, checked against decoded pixels and causal observability. A separate truth implementation and independent annotation of visible evidence must agree. Geometry ties, complete occlusion, event-order ties and ambiguous identity conventions are excluded by published rules before sealing. Do not discard only the items a particular method misses. ## Exact scoring and the physical anchor contract

Choose **pure answer quality under enforced resource caps**. There is no continuous speed, crop-count, information-gain, confidence, report, cleanup or detection reward. Observation efficiency matters because every episode must answer within its visual and execution budgets. A decorative latency term would recreate the feedback's dead-bonus failure.

The following is the complete proposed scoring algorithm; its new coefficients are **ESTIMATED**. The remaining data-dependent constants must be measured on independent calibration and placed in `REWARD_SPEC.json`. A packet with symbolic unmeasured anchors is not a deployable grader, and C4 remains OPEN until the numeric specification and executable arithmetic agree.

Index each required cell s by one of the catalog's four outcome families—spatial relation, cross-crop identity, temporal event, cross-view composition—and the proposed tight/standard budget. All eight cells have weight `w_s=1/8`. An item has four shuffled alternatives and exactly one accepted alternative index. Source evidence describes four-choice spatial queries; extending that grammar to all T10 families is an **ESTIMATED design choice**. No token-overlap or prose judge is used.

For private training seed j and item i in the committed cell ledger, let `x_ijs=1` exactly when a well-formed answer matches truth and every preceding action respected the resource rules; otherwise `x_ijs=0`. Let `e_ijs=1` for a syntactically valid terminal answer returned in budget, even if wrong, and zero otherwise. Missing, late, failed or skipped items remain indexed. Then

```
a_s = (sum_j sum_i x_ijs) / (J * N_s)
e_s = (sum_j sum_i e_ijs) / (J * N_s)
d_s = max(0, f_s - a_s, 0.90 - e_s)
g_s = max(0, a_s - d_s)
A   = sum_s w_s * a_s
U   = sum_s w_s * g_s
R   = min(1, max(0, (U - b) / (c - b)))     provided c > b
```

The source B14 completion floor is 90%; the proposed quality non-regression floor is `f_s=max(0,a_s(K)-0.02)`, applying B14's 0.02 allowance to an independently calibrated competent combined controller K. Freeze those numeric floors before validation. `A` is unpenalised macro exact accuracy; `U` is accuracy with local coverage/non-regression deductions, both in units of correct-answer fraction. No floor on one cell globally zeros other cells. A lawful specialist can earn local progress and still fail certification if a floor CI is unresolved or below threshold. Report e and a separately: valid guessing is completion, not correctness. Every training seed is an equal part of each fixed denominator.

The local map is continuous in accuracy/completion rates. Under this maximum-deficit rule, losing one completed correct item decreases a and e by the same item weight, so g decreases by at most twice that weight. Using a sum of deficits would double-charge completion and quality and violate that bound. The penalty has no cliff, and cannot improve when correctness or completion worsens. Integer-item granularity remains; continuity means no additional threshold jump. Disclose each item's native weight `w_s/(J*N_s)` and its pre-clipping final-reward weight `w_s/(J*N_s*(c-b))`; the loss bound is twice the corresponding weight. Run the perturbation check after anchors fix c-b.

All score accumulation starts from integer counts, uses exact rational arithmetic for a/e/U and frozen rational b/c/f, and emits a canonical decimal rounded to **ESTIMATED 12 places**, ties to even. Binary decisions use integer alternative IDs, not Unicode string matching. Candidate JSON rejects duplicate keys, nonfinite numbers, bool-as-int and unknown mandatory fields. A malformed action loses that episode's opportunity under its slot rules; malformed mandatory submission artifacts or a security/provenance breach invalidate the submission. Ordinary wrong answers do not invalidate other episodes.
