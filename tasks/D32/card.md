# D32 — Buy complementary robot information with the learner recipe fixed

**Generator:** information-acquisition recovery. **Stage × artifact:** data × code. **Modality:** robot video, action/contact labels and paired views.

## Problem

A robot-learning project has passive clips whose visual novelty does not identify controllable actions. Submit the eight-round information-acquisition policy in [Suite 19.5](/workspace/task_suites_claude.md:24603), buying action annotations, contact information or paired views. Representation, bridge, reliability treatment, data order and trainer remain fixed so the experiment isolates information acquisition.

## Why known recipes plateau

Deduplication, diversity/core-set selection, uncertainty sampling, contextual bandits, gradient acquisition and pair-aware information-value search are complete controls. A possible residual is complementary information on the same event ancestry: a view identifies contact side while an action annotation resolves source command semantics, and neither alone teaches the missing relation. This must be a measured learning effect, not a symbolic two-key puzzle.

## Deterministic grader

Root replays acquisitions independently for each learner replica, validates typed operations and debits all annotation/probe costs. It then executes the fixed training schedule and evaluates exact private closed-loop robot outcomes. U macro-averages affordance, recovery, nuisance-transfer and retained-skill success. Reconstruction, entropy reduction and purchased volume earn no reward. F_D32 uses fixed denominators including failed episodes.

## Hidden-score design

Fresh scene/action-support mechanisms preserve the disclosed acquisition menu, costs and eight-round cadence. Strict dev fidelity includes rare modes and sensor ambiguity, with protected goal-composition proxies. Diagnostics may reveal supervised loss only for seed or already purchased labels; unpurchased annotations and private robot outcomes stay inaccessible.
