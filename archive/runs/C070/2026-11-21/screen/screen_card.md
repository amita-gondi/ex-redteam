Index all outputs by immutable request/token identities before comparing, and record the actual behavior log probabilities at generation. This quickly separates permutation bugs from arithmetic differences; the experiment is a standard controlled comparison rather than a scarce insight a frontier researcher must discover unaided.

Use [vLLM batch invariance](https://docs.vllm.ai/en/latest/features/batch_invariance/) as a conservative numeric control, then selectively retain the cheaper original kernels where probes demonstrate acceptable semantics. If the contract permits numerical behavior/learner mismatch, use the explicitly accounted correction described in [NeMo RL's training/inference mismatch guide](https://docs.nvidia.com/nemo/rl/nightly/guides/grpo.html). That is not permission to fabricate old probabilities or claim exact parity where it does not hold. Tune batch partitioning, precision islands and refresh cadence together, retaining real policy-learning checks and measuring end-to-end cost.
