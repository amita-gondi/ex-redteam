## Task 07B

**Train an evidence evaluator that remains useful when researchers optimize against it — VERDICT: needs fixes.**

Current raw formula: `S = 0.35 d + 0.25 z + 0.40 v; z is Brier utility and v true validity after fixed-size selection.` See [07B §Reward](/workspace/task_design_v2_codex/07_measurement_and_reward.md:259). All table payouts are estimates using F above; actual anchors and attainable outcomes are to verify.

### Audit of the task’s own saturation section and kill criteria

The own section correctly identifies rendering-only saturation and irreducible ambiguity as fatal alternatives. It has not yet shown a middle regime with observable but difficult truth. More evidence length can make parsing slower without requiring research, and a fixed optimizer can be defeated by score flattening. Apply the shared kills only after a structural renderer boundary, strong priors, oracle-evidence bounds and independent attack curves are in place. Source: [07B §Saturation resistance](/workspace/task_design_v2_codex/07_measurement_and_reward.md:281); experiments: [07B §E2/E3](/workspace/task_design_v2_codex/07_measurement_and_reward.md:322). The common protocol critique above also applies.

### Verdict justification

This could become a valid evaluator-training task because the outer labels and selection outcomes are executable. It currently lacks an enforceable renderer boundary and evidence sufficiency proof, and its fixed optimizer can reward score suppression or optimizer-specific defenses. Retain for redesign only if a strong canonicalized SFT baseline leaves measurable, recoverable headroom under independent adaptive attacks.

## Primary sources used for attack recipes

- **[P14](https://arxiv.org/abs/2210.10760)** [Scaling Laws for Reward Model Overoptimization](https://arxiv.org/abs/2210.10760). Evidence that optimization against an imperfect proxy can reduce true quality; the particular finite-attacker counterstrategies here are red-team hypotheses.
- **[P17](https://arxiv.org/abs/1506.02629)** [Generalization in Adaptive Data Analysis and Holdout Reuse](https://arxiv.org/abs/1506.02629). Motivates controlling adaptive holdout reuse. A throttle alone is not a privacy or generalization proof; no complete v2 bank reconstruction is claimed.
