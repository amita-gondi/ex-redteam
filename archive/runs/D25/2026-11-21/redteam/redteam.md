## Published recipe shortcut — web checked

- [Improved Learning-Augmented Algorithms for the Multi-Option Ski Rental Problem via Best-Possible Competitive Analysis](https://proceedings.mlr.press/v202/shin23c/shin23c.pdf) establishes a family of prediction-assisted online investment algorithms with robustness to prediction error. It does not model D25's unknown learning interactions.
- [Learning-augmented Online Algorithm for Two-level Ski-rental Problem](https://arxiv.org/abs/2402.06715) explicitly handles on-demand use, individual purchases and a combined purchase, making common-core support a necessary control.
- [Voyager: An Open-Ended Embodied Agent with Large Language Models](https://arxiv.org/abs/2305.16291) supplies a concrete precedent for constructing and retrieving reusable executable skills. It is a reuse mechanism precedent, not a matched learner-campaign baseline or evidence about depreciation.

This session opened the proceedings PDF and primary abstract pages. Verification covered the stated problem formulations and high-level mechanisms; proofs, code competence and D25 compatibility were not checked experimentally. I do not transfer competitive-ratio guarantees from rent-or-buy to neural learning. The stronger claim is narrower: ordinary economic uncertainty and reusable code already have mature recipes and must be jointly tested. The proposed composition receives **ESTIMATED 0.80 (ESTIMATED 0.53–0.96)**, with unknown reward anchors preventing a calibrated prediction.

## Saturation against the hypothetical 10T researcher / 12h

The target can treat the controller as a finite-horizon partially observed investment process, fit return estimates from paid campaign probes and compare conservative reuse against investment abstention. It can also write support that is reusable by construction rather than learn when to reuse a poor inventory. None of these actions needs the designer's proposed interpretation of the campaigns.

The right-hand comparison values are the request's fixed kill thresholds. These forecasts describe plausible saturation of the specified operational structure, not actual campaign results or fitted confidence limits. If the unknown support-learning interactions dominate instead, the forecast can be wrong; the source does not currently instantiate such an interaction well enough to justify retention.

S1 remains unestablished because construction, learner work and final capability have no measured joint frontier. A nominal distant endpoint cannot prove that better support is attainable at the same lifetime cost. S7 additionally asks whether the controller exhausts the attainable lifecycle benefit. A physically small reuse advantage may already be nearly saturated even when normalized reward looks moderate. The ceiling must come from a legally deployed portfolio, not a planner supplied future returns.

Observed best-of-four, pass@4, single-run outcomes and projection fits are **UNMEASURED**. Their planned measurement uses independent campaign sequences with all scheduled learners retained, distinguishes oracle selection from lawful proxy selection, and charges complete lifetime work for every attempt. Grader noise is **UNMEASURED**; repeat identical portfolios across learner seeds and replay support-use histories before attributing small advantages to policy quality. The weakness reports cannot justify assuming that the target forgets past investments, stops early or fails to maintain the ledger.

## Verdict, required fixes and cheapest decisive check

**CUT this underinstantiated proposal.** Re-entry requires an explicit reusable training asset and a real support-by-learner-by-campaign interaction after modular build-all, never-invest and full-cost online planning controls. This is a substantive scientific construction, not a bounded ledger patch.

The cheapest decisive check is a CPU state-transition audit at **ESTIMATED 0 H100-hours**. For an author-supplied candidate campaign, trace which variables determine future support returns. If the outcome is a fixed table indexed by public context, depreciation and usage, build the dynamic-programming/online-planning reduction on paper and reject the claimed learning depth. If learned state truly changes later returns, specify the competing causal trajectories and only then price actual learner fits. This desk audit can establish a structural planning collapse, but failure to establish it is not a saturation pass.

For any successor, Round 2's portable root lifecycle, immutable ledger, bounded retained checkpoints, timeouts and retained candidate failures are essential. Positive support implementations must run independently; an inventory receipt, static hash or cleanup operation cannot earn capability credit. No live exploit or GPU campaign was run here.
