# C128 — A self-improvement loop that can reverse its own bad update — saturation screen
## 1. What the grader actually rewards
The selected final scaffold is reset and judged by real research gains on independent private projects after a budgeted self-upgrade chain. Every rejected branch and validation attempt counts, and rollback must restore tools plus the evidence state used for decisions. ESTIMATED R≈0 is a competent versioned search and independent-validation floor; ESTIMATED R≈1 is an attainable stronger final researcher under the same full cost. Greedy local acceptance and the unchanged scaffold need native campaign outcomes before interpreting the planned ESTIMATED reference around 0.60.
## 2. Strongest lawful combined attack
Make each scaffold/data candidate an immutable branch with captured dependencies, legal training records, evaluator version, random state and cost ledger. [DVC experiment management](https://doc.dvc.org/user-guide/experiment-management) verifies existing pipeline versioning and reproduction facilities; it is useful infrastructure but does not by itself restore a live agent's complete state. Add explicit snapshots for the remaining allowed state and verify reconstruction by replaying committed requests rather than trusting a version name.

Generate candidate tool, prompt and data-policy changes using an optimization loop such as [DSPy](https://arxiv.org/abs/2310.03714) or [TextGrad](https://arxiv.org/abs/2406.07496), while treating their feedback as untrusted proposals. Promote candidates through cheap invariants, independent development campaigns and final fresh reset tests. Keep the evaluation service outside the editable branch, rotate lawful probe content, and select using paired utility after all branch costs. Preserve several independently successful branches and revert whole coupled tool/data changes when the external comparison degrades. Selecting one intact branch requires no model-parameter combination.

ESTIMATED single-run R=0.78, range 0.55–0.92; ESTIMATED oracle best-of-4=0.87; ESTIMATED pass@4 at R≥0.60=0.97; ESTIMATED projected upper-95% score=0.96. Co-adaptation to a finite validation distribution remains possible, particularly across chains of locally useful changes. However, independent project validation and reset replay are standard solutions to precisely that problem. The card does not specify a costly delayed interaction that defeats them, and complete rollback snapshots are primarily engineering rather than a new scientific mechanism.
## 3. Other routes
Versioned scaffold search with independent held-out acceptance is the strongest single recipe. ESTIMATED R=0.64, range 0.42–0.83. It avoids the largest local-self-test errors even with simple greedy proposals.

A beam or evolutionary search across coupled tool/data upgrades, with sequential campaign promotion, has ESTIMATED R=0.73, range 0.49–0.90. The beam uses independent artifacts rather than blending model states, and every branch consumes its actual bill. A lawful conservative route applies only isolated upgrades whose gains reproduce from the original ancestor: ESTIMATED R=0.66, range 0.39–0.86. It may give up some synergistic gains but sharply reduces chain-induced comparison failures without learning a special rollback policy.
## 4. What would lower lawful saturation
Require an authentic upgrade interaction where a short-term regression enables a later scientific gain, with affordable evidence distinguishing that route from evaluator overfit. Preserve independent probes and matching branch costs in dev, and compare full versioned search against a reference that uses the delayed information. ESTIMATED attack reduction is 0.14–0.22, to around 0.56–0.64, still problematic for repeated search. ESTIMATED redesign effort is 15–25 person-days and 360 H100-h for real upgrade-chain histories. Longer trees alone increase search volume without demonstrating the proposed dependent insight.
