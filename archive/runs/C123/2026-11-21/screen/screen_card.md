## 2. Strongest lawful combined attack
Persist complete legal event records outside the active context and maintain a compact index of hypotheses, unresolved contrasts, experiment receipts, checkpoint ancestry and next actions. [MemGPT](https://arxiv.org/abs/2310.08560) verifies hierarchical virtual context management. [Anthropic's context-engineering guidance](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents) verifies compaction and structured notes as established agent techniques. The recently indexed [Folio](https://arxiv.org/abs/2611.16627) provides an especially close precedent for linked notes, event manifests and recoverable source records; no reported performance from it is imported into this screen.

The attacker would snapshot a structured continuation record before turnover, including competing predictions rather than only current conclusions. On resumption, load the active dependency frontier and fetch exact source records when a new result changes which contrast matters. Link every summary assertion to an event identifier so lossy compression can be reversed by retrieval. Periodically compare intended next experiments against the ledger to prevent duplicate execution. Optimize page size, graph expansion and retrieval allocation on full development campaigns. All storage construction, retrieval tokens and agent work stay charged. The new process receives only the allowed pager state, so the attack does not rely on hidden caches surviving rollover.
