## Saturation against the hypothetical 10T researcher / 12h

The core question is not whether donor rows can carry harmful conventions; it is whether resolving uncertain history is necessary after exact outcome/legality checks and alternative safe teaching. If raw action semantics uniquely establish eligibility, version attribution can become an accounting task with no remaining learning contribution. If genuinely necessary donor context is missing, different histories may require opposite eligibility decisions from identical available evidence. That would fail identifiability. The admissible middle case needs a specified evidence model where lawful uncertainty reduction predicts different recipient benefits.

The linked suite largely assumes authenticated immutable lineage and an exact eligibility predicate. The card introduces imperfect joins, but never specifies which event fields are uncertain, who can resolve them, or what remains visible after root ownership. A build must not quietly give the reference exact labels while the baseline estimates joins. Strong contextual gating can use the same evidence without reconstructing the designer's explicit attribution graph. Likewise, synthesizing safe demonstrations is a legal bypass only to the extent the frozen data interface admits it; I do not assume permission to upload arbitrary replacement rows.
